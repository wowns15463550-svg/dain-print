# 다인인쇄소 홈페이지

서울 충무로 다인인쇄소(다인시스템) 홈페이지입니다.
주소: https://wowns15463550-svg.github.io/dain-print/

## 공지사항 고치는 법 (휴대폰으로도 가능)

1. 이 저장소에서 `content/notices.json` 파일을 엽니다.
2. 오른쪽 위 연필 아이콘(Edit)을 누릅니다.
3. 맨 위에 새 공지를 아래 모양 그대로 추가합니다. 위에 있을수록 먼저 보입니다.

```json
  {
    "date": "2026.10.10",
    "tag": "공지",
    "hot": true,
    "title": "공지 제목",
    "body": "공지 내용"
  },
```

- `tag`는 `공지`, `안내`, `휴무` 처럼 짧게 씁니다.
- `"hot": true` 를 넣으면 파란색으로 강조됩니다. 필요 없으면 그 줄을 지웁니다.
- 공지와 공지 사이에는 쉼표(,)가 있어야 하고, 마지막 공지 뒤에는 쉼표가 없어야 합니다.

4. 아래 **Commit changes** 를 누르면 1~2분 뒤 홈페이지에 반영됩니다.
   진행 상황은 저장소의 **Actions** 탭에서 볼 수 있습니다.

## 그 밖의 내용

- 연락처, 품목, 장비, 자주 묻는 질문: `src/site-data.ts`
- 사진: `public/assets/` 의 파일을 같은 이름으로 바꿔 올리면 교체됩니다.
